# ChatGPT 网页增强

一个无依赖的 Chrome / Edge Manifest V3 扩展，为 ChatGPT 网页提供回答目录、用户问题时间轴和推广弹窗自动关闭等增强功能。

当前版本：`0.8.0`

## 功能

- 在 ChatGPT 顶部“更多”按钮右侧显示唯一的常驻目录按钮，滚到回答任意位置都能使用。
- 在目录按钮右侧提供“返回”和“前进”按钮；目录、时间轴、问题列表或快捷键跳转后，可以回到跳转前的阅读位置，也能再次前进。
- 跳转历史使用稳定轮次 ID、阅读线相对偏移和滚动位置三重定位；长对话发生虚拟挂载时仍会持续校准，切换对话后自动清空。
- 按钮随滚动自动识别当前正在阅读的助手回答，每次只展示该回答的标题，不会混入其他回答。
- 用缩进和 `H1`–`H6` 标记展示大纲层级。
- 点击目录项时重新解析当前回答和标题，避免 ChatGPT 重渲染后命中失效节点。
- 使用统一导航队列直接定位真实滚动容器，并持续校准到目标稳定或用户主动中断。
- 自动处理流式回答、新消息和 ChatGPT 单页导航。
- 当前回答没有标题时，顶部目录按钮保持可见但处于禁用状态。
- 支持键盘焦点、`Escape` 关闭和“减少动态效果”系统设置。
- 自动关闭 ChatGPT 的“获取 Pro / Get Pro”推广弹窗；只匹配推广弹窗，不会点击普通弹窗的关闭按钮。
- 不申请额外权限，也不发送网络请求。

### 对话时间轴

- 固定在网页左侧，以等距浅灰短横线呈现，不显示外框、竖线或标题栏；即使网页原生时间轴偶尔恢复，也不会与插件时间轴重叠。
- 每条短横线只对应一条用户问题；ChatGPT 回复不会生成节点。
- 点击短横线跳转到问题；悬停或聚焦可预览问题内容。
- 鼠标悬停在时间轴区域时显示列表按钮；点击后展开带序号的问题列表，可搜索全部已索引的用户问题并点击跳转。
- 当前问题使用稍长、稍深的短横线表示。
- 时间轴与顶部目录共用视口约 32% 处的阅读线：进入某个回答区域后，目录绑定该回答，时间轴同时聚焦它所属的问题，不必等问题文本滚到页面顶部。
- 当前问题优先按所有已索引问题的缓存绝对位置判断，问题节点被虚拟卸载后仍能正确聚焦；用户滚动会立即解除点击跳转产生的临时聚焦。
- `j` / `k` 跳转到下一个/上一个问题，`gg` / `GG` 跳转到首尾问题。
- 使用稳定的 `data-turn-id` 记录问题；不再把会随虚拟窗口重编号的 `conversation-turn-N` 当成消息身份。
- 自动接管带有标准语义标记的原时间轴，并持续处理 ChatGPT 单页导航、滚动容器替换和长对话虚拟加载。
- 首次只挂载后段消息时，时间轴顶部会显示一条更短的加载标记；点击后会反复触发并等待更早问题挂载，完成后该标记消失。

## 安装

1. 打开 `chrome://extensions` 或 `edge://extensions`。
2. 开启“开发者模式”。
3. 选择“加载已解压的扩展程序”。
4. 选择本项目根目录（包含 `manifest.json` 的 `chatgpt-answer-toc` 文件夹）。
5. 打开或刷新 <https://chatgpt.com/>。

## 从旧版本更新

如果已经加载过旧版本：

1. 用当前版本文件替换旧扩展目录，或直接重新选择本项目根目录。
2. 在 `chrome://extensions` 或 `edge://extensions` 找到本扩展，点击“重新加载”。
3. 回到 ChatGPT 页面，按 `Ctrl+Shift+R` 强制刷新。

`0.8.0` 新增页内跳转历史。顶部目录按钮右侧增加“返回”和“前进”按钮，目录与时间轴的成功跳转会共同写入历史；返回后如果发起新的跳转，旧的前进分支会自动丢弃。位置恢复优先使用稳定 `data-turn-id` 和阅读线内偏移，并以滚动位置作为虚拟列表尚未挂载目标时的兜底。

`0.7.1` 修复左侧时间轴进入 ChatGPT 侧边栏的问题。时间轴与问题搜索面板现在挂载到包含当前对话的 `[data-side-pane-shell-host="true"]` 主内容容器，并相对该容器定位；ChatGPT 单页导航替换容器时会自动迁移到新的主内容容器。

`0.7.0` 新增时间轴问题列表与搜索。鼠标悬停或键盘聚焦时间轴时显示绿色列表按钮；面板只列出用户问题，支持中文、英文及多关键词搜索。点击结果继续使用稳定 turn ID 和虚拟列表定位逻辑；点击面板外部或按 `Escape` 可关闭。

`0.6.2` 将插件时间轴由网页右侧移到左侧，避免与偶尔恢复显示的 ChatGPT 原生时间轴重叠；节点提示框同步改为向右展开，并在窄屏中保留安全边距。

`0.6.1` 将扩展显示名称由“ChatGPT 目录与时间轴”改为“ChatGPT 网页增强”，以覆盖目录、时间轴和页面自动化等多类功能。现有项目目录保持不变，重新加载后不会因为文件夹改名而生成重复的未解压扩展。

`0.6.0` 新增“获取 Pro”推广弹窗自动关闭功能。关闭按钮必须同时满足稳定的 `data-testid="close-button"` 属性，并位于含有“获取/升级/订阅 Pro”明确文案的模态框内；首次加载、延迟弹出和 ChatGPT 单页重渲染都会重新检测，普通关闭按钮不会被点击。

`0.5.3` 统一目录与时间轴的功能切换逻辑。两者现在共用视口约32%处的阅读线；阅读线进入回答区域时，目录选择该回答，时间轴同步选择它前面的用户问题，不再要求问题节点滚动到顶部附近才切换。

`0.5.2` 修复当前问题已被 ChatGPT 虚拟列表卸载时，时间轴错误回退到后续第一个挂载问题的问题。新版使用经稳定 turn ID 锚点校正的缓存绝对位置划分问题区间；即使用户问题节点卸载、对应长回答仍在屏幕中，也能维持原问题高亮。到达对话滚动底部时会选择最后一个缓存问题，覆盖末条问题无法滚到阅读线的边界。

`0.5.1` 修复时间轴高亮停留在错误问题的问题。旧版点击节点后会把高亮锁定最长约 16 秒，即使用户已经滚动到其他问题也不会更新；新版只在实际导航期间保持目标高亮，用户输入会立即解除，并按最新 DOM 屏幕坐标重新选择当前问题。

`0.5.0` 将原先位于每条回答末尾的目录按钮改为顶部全局按钮。它被插入 `conversation-options-button` 的右侧，并根据视口阅读位置自动绑定当前回答；打开目录后会锁定该回答，避免滚动目录面板时意外切换。到达对话底部时会直接绑定最后一条回答，覆盖末条回答无法滚到常规阅读线的情况。

`0.4.1` 修复时间轴仍可能落到错误问题的问题。时间轴现在保存问题在滚动内容中的真实绝对坐标；旧消息前插导致坐标整体移动时，会使用仍挂载的稳定 turn ID 作为锚点，同步修正所有缓存坐标，而不是按问题数量比例估算。

`0.4.0` 重写了目录与时间轴导航。真实 ChatGPT 长对话会虚拟化消息，并在装载旧消息时整体重编号 `conversation-turn-N`、改变滚动高度；新版只用稳定 turn ID 识别问题，每次跳转都重新解析目标和滚动容器，并在虚拟挂载与滚动锚定结束后再次校准。

`0.3.1` 曾尝试修复回答目录长距离跳转，但仍保留了失效 DOM 引用和不稳定轮次序号，无法覆盖 ChatGPT 的真实虚拟列表行为。

`0.3.0` 将时间轴改为用户问题专用的简约短横线导航，并移除星标、层级、折叠、缩放及本地存储权限。

如果你把 ChatGPT 网页“安装为应用”，该应用窗口仍使用 Chrome / Edge 的网页运行环境，扩展通常也会生效。OpenAI 原生 ChatGPT Windows / macOS 客户端本身不加载 Chrome / Edge 扩展。

## 使用

滚动到想查看的 ChatGPT 回答，在页面顶部“更多”按钮右侧点击目录图标。角标数字表示当前回答检测到的标题数；列表缩进表示标题相对层级。点击任意目录项即可跳转。完成至少一次跳转后，“返回”按钮会启用；返回后，“前进”按钮会启用。普通鼠标滚动不会产生历史条目，但会更新当前历史位置。

时间轴会在已有用户问题的对话右侧自动出现。它只读取当前页面中的问题文本用于悬停预览和页内跳转，不保存或上传对话内容。

时间轴的 compact 短横线视觉与用户轮次导航思路参考了开源项目 [Voyager](https://github.com/Nagi-ovo/voyager)；本扩展针对 ChatGPT 的 DOM 与需求独立实现。

## 页面契约

扩展只依赖下列语义结构：

- 回答轮次：优先 `[data-testid^="conversation-turn-"][data-turn="assistant"]`，并以 `[data-turn="assistant"]` 作为回退；不依赖容器是 `article` 还是 `section`。
- 助手身份：回答内部存在 `[data-message-author-role="assistant"]`。
- 大纲标题：当前回答内部的 `h1, h2, h3, h4, h5, h6`。
- 顶部按钮锚点：`[data-testid="conversation-options-button"]`；目录、返回和前进按钮插入其外层操作槽的右侧，不依赖 SVG sprite 的哈希值。
- 时间轴节点：`[data-testid^="conversation-turn-"][data-turn="user"]`；节点身份必须使用稳定的 `data-turn-id`，`conversation-turn-N` 只参与元素发现，不参与排序或缓存。
- 时间轴挂载容器：优先选择包含当前对话轮次的 `[data-side-pane-shell-host="true"]`；时间轴与搜索面板均作为该主内容容器的子元素，不挂载到页面 `body` 或左侧导航栏。
- Pro 弹窗关闭按钮：`button[data-testid="close-button"]`，并额外校验按钮所属模态框的推广文案；SVG sprite 哈希值不参与识别。

若 ChatGPT 将来移除这些语义属性，需要根据新版页面 DOM 更新选择器。
